# Region příležitostí a budoucnosti

Web Pardubického kraje, který představuje vybrané neinvestiční projekty regionálního rozvoje. Statický web v [Astru](https://astro.build), nasazovaný na Vercel.

Zadání webu (struktura, data, vizuál, pravidla obsahu) je v dokumentu `RPB_web_MASTER` (verze 0.4).

## Práce s projektem

```sh
npm install      # stažení závislostí
npm run dev      # náhled na http://localhost:4321
npm run build    # sestavení webu do složky dist/
```

## Nasazení

Každá změna ve větvi `main` se na Vercelu automaticky sestaví a zveřejní. Změny v jiných větvích dostanou náhledovou adresu ke kontrole.
